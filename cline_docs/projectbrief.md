# Project Brief: GenesisIdleRPG

## Overview
Genesis: Goddess of Creation is a Godot 4 cosmic idle RPG. Players generate Quanta, weave subatomic particles into galaxies, collect celestial relics, invoke miracles, and evolve the goddess Zenda.

## Core Goals
- High-performance, clean GDScript 4 architecture.
- Modular Autoload architecture (`DB`, `Game`).
- Built-in runtime AI integration for ChatGPT & MiniMax.
- First-class AI agent tooling via Godot MCP (`Coding-Solo/godot-mcp`).
