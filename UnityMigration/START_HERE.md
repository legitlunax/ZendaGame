# Genesis Idle RPG — Unity migration handoff

This is a data/source/art handoff, NOT a completed Unity project. No Unity editor
build has been tested. Preserve this package before changing either engine project.
The exported runtime catalog and source snapshots are the parity baseline.

## Contents

- `Data/catalog.json`: all 106 fully expanded generators, 107 chapters, 29 dimension
  milestones, six goddess forms, three relics, two miracles, number suffixes, fairy
  names, 18 demo presets, ten emotion states, and six wardrobe designs.
- `Data/demo_snapshots.json`: exact preset states and expected production/objectives.
- `Data/parity_fixtures.json`: 120 numerical purchase/production cases and formatting
  examples, generated by the Godot runtime rather than retyped by hand.
- `Data/save_template_godot.json`: clean deterministic opening fixture. Timestamp
  zero is a test sentinel, not a timestamp to award offline income against.
- `Data/character_hierarchy.json`: procedural attachment hierarchy and transforms.
- `Data/emotion_pose_samples.json`: 60 sampled pose hierarchies, not animation clips.
- `Data/fairy_prototype.glb`: static reference geometry. No rig, skin weights, or
  authored animation clips. Custom shader materials need rebuilding in Unity.
- `ReusableAssets`: 126 hashed original SVG/PNG/WAV assets and provenance notes.
- `SourceSnapshot`: GDScript, shaders, scene, tests, catalog source, docs, generator,
  and exporter. Preserve these even if you replace all visuals.
- `Screenshots`: layout/visual references of mixed ages; use wardrobe and portrait
  images for the more recent main-character appearance. Some older captures predate
  the graphics passes. No screenshot proves physical-phone performance.
- `RECREATION_GUIDE.md`: system mapping, math, UI, animation and save contracts.
- `Tools/convert_save.py`: optional explicit-input save converter; standard library.
- `Tools/test_save_converter.py`: migration tests that never access a player save.
- `VALIDATION.json`: checks actually performed; no implied Unity verification.
- `PACKAGE_MANIFEST.json`: byte size and SHA-256 for each packaged file except itself.

## Start in Unity

1. Choose and pin your Unity editor and render pipeline; neither is prescribed by
   the Godot source. Do not silently change engine versions during recreation.
2. Read the recreation guide and import `Data/catalog.json` into your data layer.
   Keep economy values as C# `double`, not Unity `float`. Late costs exceed float
   range. Use stable string IDs for persistence, never display names or array indices.
3. Recreate the pure economy/state layer and pass the fixtures BEFORE porting UI.
4. Import WAV/PNG files directly through the editor. SVG support needs a suitable
   vector importer or offline rasterization; it is not assumed installed. Preserve
   the SVG originals. Use an explicitly selected glTF importer for the GLB, or
   convert in your DCC tool; do not assume GLB is a native drop-in Unity model.
5. Rebuild the UI and isolated character camera. Port poses only as interim logic;
   the intended character direction needs an authored adult anime model and rig.
6. Implement save migration, chapter unlocks, and wardrobe selection, then test
   the same responsive sizes and actual target devices.

## Save conversion (optional)

Your real player save is deliberately NOT included. In Godot, find its user-data
folder with the editor's Open User Data Folder action and back up
`genesis_save_v1.json`. Do not copy `ai_credentials.json` into Unity or this package.

Run from this extracted package, with explicit absolute paths:

```powershell
python 'E:\Godot\GenesisIdleRPG\UnityMigration\Tools\convert_save.py' 'C:\YourBackup\genesis_save_v1.json' 'C:\YourBackup\genesis_unity_v1.json'
```

The destination must not already exist. The converter never alters the original,
does not apply offline rewards, filters unknown IDs, and uses list-based count
entries for simpler Unity serialization. Preserve the original timestamp. The
Unity implementation must award elapsed income exactly once on first load.

## Rebuild the handoff from the Godot source project

```powershell
& 'E:\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path 'E:\Godot\GenesisIdleRPG' --editor --quit
& 'E:\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path 'E:\Godot\GenesisIdleRPG' --script 'res://tools/ExportUnityData.gd' -- --demo
python 'E:\Godot\GenesisIdleRPG\UnityMigration\Tools\test_save_converter.py'
python 'E:\Godot\GenesisIdleRPG\tools\package_unity_migration.py'
```

Rebuild from the original project, not from SourceSnapshot alone. All generated
assets are copied from the verified manifest. The allowlist excludes user data,
credentials, build outputs, editor caches, local MCP settings and signing files.
The personal visual-reference JPG is not redistributed; its path and design
direction are documented in the source docs. No authored anime character asset
exists in the source to transfer.
